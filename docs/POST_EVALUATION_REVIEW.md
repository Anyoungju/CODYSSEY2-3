## 증빙 원칙

- 실제 운영 호출, 로그, 화면을 확인하지 못한 항목은 완료로 표시하지 않는다.

- 비밀값, 전체 Request ID, 사용자 입력 원문은 스크린샷과 로그에서 제거한다.
