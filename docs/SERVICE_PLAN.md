# Codyssey Compass 서비스 기획서

## 1. 목적과 대상 사용자

Codyssey Compass는 웹 서비스를 처음 기획하는 학습자가 막연한 아이디어를 실행 가능한 MVP 청사진으로 바꾸도록 돕는다. 주요 사용자는 AI 코딩 도구를 활용해 첫 프로젝트를 만들고 싶지만, 화면 구성과 개발 우선순위를 정하기 어려운 입문 개발자다.

## 2. 페이지·섹션 구조

| 구역 | 목적 | 핵심 행동 |
| --- | --- | --- |
| Home | 서비스 가치와 방향 소개 | AI 설계실로 이동 |
| 서비스 소개 | 해결하는 문제와 차별점 설명 | 기능 이해 |
| AI 설계실 | 아이디어·사용자·조건 입력 | 청사진 생성 |
| 결과 | 화면, AI 기능, 개발 순서, 위험 표시 | 결과 복사 |
| 진행 방법 | 아이디어부터 배포까지의 흐름 안내 | 실행 시작 |

한 페이지 안에서 메뉴로 각 섹션을 이동하는 구조이며, 데스크톱과 모바일에서 모두 사용할 수 있다.

## 3. 핵심 기능

- 한 줄 아이디어와 선택 정보를 입력받는다.
- Python 서버리스 함수가 OpenAI Responses API에 요청한다.
- 서비스 이름, 설명, 3개 이상의 화면, AI 기능, 4단계 로드맵, 위험 요소를 구조화해 보여준다.
- 결과를 클립보드로 복사할 수 있다.
- 테마 선택은 브라우저에 보존한다.

## 4. AI 기능 기준

- 입력: 서비스 아이디어(필수, 최대 600자), 대상 사용자, 우선 조건
- 출력: 서비스 청사진 JSON을 화면용 카드로 변환
- 사용자 가치: 무엇을 어떤 순서로 만들지 빠르게 결정하고 첫 구현에 집중
- 실패 처리: 빈 입력은 클라이언트에서 즉시 차단한다. API 미설정·오류는 입력을 보존한 채 한국어 메시지를 표시한다. 브라우저 요청은 20초 후 중단하며 재시도를 안내한다.
- 비용·품질: 모델은 `OPENAI_MODEL`로 교체할 수 있고, 입력 길이와 재시도 횟수를 제한한다.

## 5. 기술 및 보안 원칙

- 프론트엔드: Vanilla HTML/CSS/JavaScript
- 백엔드: Python 3.12+ Vercel Function
- AI: OpenAI Responses API
- 비밀키는 서버의 `OPENAI_API_KEY` 환경변수에서만 읽으며 코드, 브라우저, 문서에 기록하지 않는다.
- 모델 출력을 JSON으로 파싱하고 최소 스키마를 검사한 뒤 클라이언트에 전달한다.

## 6. 완료 기준

1. 두 가지 이상 화면 너비에서 메뉴, 폼, 결과가 깨지지 않는다.
2. 빈 입력, API 미설정, 시간 초과의 안내가 확인된다.
3. API 키를 설정한 Vercel 환경에서 실제 청사진이 생성된다.
4. 저장소와 배포 URL이 README에 연결된다.
